## 🚀 Featured Projects


### 🧠 [Parkinson's Disease Detection App](https://github.com/Annefern96/parkinson_detection_app)

Developed an AI-powered application to predict Parkinson's disease risk using voice biomarker data and machine learning. Built an interactive Streamlit dashboard supporting individual and batch predictions, confidence scores, and model explainability using SHAP. Integrated MLflow for experiment tracking and model management.

**Technologies:** Python · XGBoost · Scikit-learn · SHAP · Streamlit · MLflow

### 📊 [Customer Churn Prediction Model](https://github.com/Annefern96/churn_prediction-model)

Developed an end-to-end machine learning pipeline to predict customer churn and support data-driven customer retention strategies. Performed data preprocessing, feature engineering, categorical encoding, and class imbalance handling. Compared multiple classification algorithms using cross-validation and business-oriented evaluation metrics.

**Technologies:** Python · Scikit-learn · Pandas · NumPy · Matplotlib · Git

### 📱 [Mobile Device Usage & User Behaviour Classification](https://github.com/Annefern96/User-behaviour-on-Mobile-Device-Usage)

Developed a multi-class machine learning model to classify smartphone users into five behavioural categories using structured mobile usage data from 700 users. Built reproducible preprocessing pipelines and compared multiple classification algorithms using standard evaluation metrics.

**Technologies:** Python · Scikit-learn · Pandas · NumPy · Matplotlib · Seaborn · Git

### 🤖 [AI Meeting Assistant](https://github.com/Annefern96/AI-Meeting-Assistant)

Built a Streamlit-based AI application that transforms unstructured meeting notes into executive summaries, decisions, action items, risks, and professional follow-up emails. Integrated Claude API with reusable prompts, structured outputs, and human-review safeguards.

**Technologies:** Python · Streamlit · Claude API · Prompt Engineering · Git
